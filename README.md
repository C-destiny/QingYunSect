# 青云宗

《青云宗》是一款面向 PC 的轻 RTS 修仙宗门经营游戏。玩家从一片有限的宗门土地开始，安排弟子生产资源、建造设施、培养精英角色，并通过挂机闯关与肉鸽副本推动宗门成长。

## 当前里程碑

V0.1 宗门经营原型：

- 基础宗门地图（已完成首版 8×6 等距网格）
- 木材、灵石、灵谷资源状态（已完成）
- 地图资源点选择与信息面板（已完成）
- 三名普通弟子的岗位分配与自动采集（已完成）
- 五种核心建筑
- 三名普通弟子的岗位分配
- 建造与短时间施工
- 本地存档与读档

## 开发环境

- Godot 4.7.2 Standard
- GDScript
- Windows x86_64
- Compatibility 渲染器
- 设计分辨率 1920×1080

## 运行

使用 Godot 4.7.2 打开根目录的 `project.godot`，然后运行项目。
