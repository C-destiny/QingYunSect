# 青云宗

《青云宗》是一款面向 PC 的轻 RTS 修仙宗门经营游戏。玩家从一片有限的宗门土地开始，安排弟子生产资源、建造设施、培养精英角色，并通过挂机闯关与肉鸽副本推动宗门成长。

## 当前里程碑

V0.1 宗门经营原型（功能验收完成）：

- 基础宗门地图（已完成首版 8×6 等距网格）
- 木材、灵石、灵谷资源状态（已完成）
- 地图资源点选择与信息面板（已完成）
- 三名普通弟子的岗位分配与自动采集（已完成）
- 版本化本地存档、读档与工作期间自动保存（已完成）
- 五种建筑的数据、预览、占地、扣费与施工流程（已完成）
- 建筑效果、详情、拆除与资源返还（已完成）
- 弟子招募、人口上限、灵谷消耗与缺粮惩罚（已完成）
- 演武场修炼、个人修为、炼气境界与突破（已完成）
- 普通弟子名册、自动姓名、个人岗位与境界采集加成（已完成）
- 1280×720侧栏滚动与界面适配（已完成）
- Windows x86_64测试版本导出配置（已完成）

详细验收结果见 `docs/V0.1_ACCEPTANCE.md`。

V0.2 宗门发展（已完成）：

- 指定具体弟子调岗，支持空闲、三类采集和演武场修炼
- 名册按状态筛选，按姓名、境界、修为和岗位排序
- 修为进度条与可突破弟子标记
- 五类建筑等级1～3升级、升级计时与等级效果

详细验收结果见 `docs/V0.2_ACCEPTANCE.md`。

V0.3 挂机战斗原型（已完成）：

- 最多三人的战斗队伍编成，入队自动离开原生产或修炼岗位

- 每秒一回合的自动战斗、胜利后自动重复与失败自动停止
- 木材、灵石、灵谷战斗奖励直接回流宗门资源
- 队伍、关卡进度、战斗现场、累计胜场和奖励完整存档

详细验收结果见 `docs/V0.3_ACCEPTANCE.md`。

## 开发环境

- Godot 4.7.2 Standard
- GDScript
- Windows x86_64
- Compatibility 渲染器
- 设计分辨率 1920×1080

## 运行

使用 Godot 4.7.2 打开根目录的 `project.godot`，然后运行项目。

Windows测试版本可通过 `Windows Desktop` 导出预设生成到 `builds/`。
