# V0.8 视觉方向基线

状态：QYS-V08-001开发中。本文件是实现约束，不等于最终美术验收。

## 核心描述

明快卡通国风的山中修仙宗门。以青绿山水和暖色木构为主体，米白纸面承载信息，朱砂用于危险/重要操作，鎏金用于成长与奖励。画面清爽、有手绘温度，但交互轮廓和小字号信息必须清晰。

## 调色板

| 语义 | 色值 | 用途 |
|---|---|---|
| 墨青 | `#173A36` | 主背景、深色面板 |
| 松绿 | `#3F745E` | 正常操作、已解锁区域 |
| 玉青 | `#70A894` | 悬停、辅助高亮 |
| 云纸 | `#F1E7C9` | 主文字、浅色信息面 |
| 砂岩 | `#C9B88A` | 次级文字、边框 |
| 鎏金 | `#D5A849` | 奖励、等级、当前目标 |
| 朱砂 | `#C65B48` | 危险、拆除、错误 |
| 天青 | `#79B9C1` | 灵气、信息提示 |

## UI组件

- 面板：深墨青半透明底，双层细边框；外轮廓松绿，内线砂岩，避免厚重金属框。
- 按钮：中等圆角，默认松绿，悬停玉青，按下略暗；危险按钮只使用朱砂，不与主操作争夺注意力。
- 文字：标题、区块标题、正文、辅助说明四级；正文不得依赖纯颜色表达状态。
- 进度条：深色槽、玉青或鎏金填充，必须同时有文字或数值。
- 图标：圆润剪影、2～3层色块、统一左上光源；16～32像素显示时仍能辨识。
- 动效：0.12～0.25秒的淡入、轻微位移或缩放；逻辑结果先于表现确认。

## 等距场景

- 地块逻辑尺寸固定104×52，素材可带透明外延但点击判定不变。
- 建筑统一朝向右下，左上主光源，阴影落向右下。
- 建筑主体高度建议80～150像素，底座不超过单格菱形边界；高层装饰可越界但不得遮住关键选择反馈。
- 核心区偏暖青绿，东部区域偏岩石与松林，南部区域偏灵田与雾气；通过色温和植被区分，不改变资源含义。

## 禁止方向

- 不采用昏暗写实、血腥、赛博、欧美厚重奇幻或高饱和手游霓虹风。
- 不在位图中生成需要准确阅读的中文文字；文字由Godot控件渲染。
- 不使用来源不明字体、纹理、图标或音效。
- 不用美术资产承载碰撞、计时、奖励或存档逻辑。
