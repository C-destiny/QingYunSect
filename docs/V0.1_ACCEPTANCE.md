# V0.1 宗门经营原型验收

验收日期：2026-10-16

## 验收结论

V0.1 核心功能通过验收，可以进入阶段封版和试玩。当前版本已形成“安排弟子—采集资源—建造设施—扩大人口—修炼突破”的可运行循环。

## 已通过项目

- 1280×720窗口正常显示顶部资源栏、地图和侧栏。
- 侧栏内容超出可视高度时可以滚动访问，不再挤压顶部区域。
- 木材、灵石、灵谷生产与建筑加成正确结算。
- 弟子灵谷消耗、缺粮效率惩罚和维持时间正确结算。
- 建筑放置、占地、扣费、施工、效果、选择与拆除正常。
- 弟子居人口上限、招募计时和招募存档正常。
- 弟子姓名、岗位、境界、个人修为、突破和采集加成正常。
- 演武场修炼位、修为分配和拆除保护正常。
- 本地保存、读取、自动保存和旧聚合存档迁移正常。
- Windows x86_64导出配置可用。

## 自动化覆盖

- 弟子分配与资源生产
- 本地存档与读档
- 建筑放置、施工与持久化
- 弟子招募
- 弟子日常消耗与缺粮
- 建筑详情、拆除返还和安全限制
- 演武场训练与修为
- 弟子名册、境界突破、岗位和旧存档迁移

## V0.1之后

V0.2优先完善指定弟子调度、名册筛选、建筑升级和宗门等级。挂机战斗、肉鸽副本和联机不纳入V0.1。
