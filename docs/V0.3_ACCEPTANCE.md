# 青云宗 V0.3 挂机战斗原型验收

## 验收范围

- 战斗队伍最多三人，弟子加入队伍后不再参与采集或修炼。
- 弟子生命、攻击、防御由炼气境界实时计算并汇总为队伍属性。
- 五个普通关卡按顺序解锁，界面显示敌人、奖励和锁定状态。
- 自动战斗每秒结算一回合；胜利领取奖励并在两秒后重复，失败自动停止。
- 关卡奖励包含木材、灵石和灵谷，并直接加入宗门现有资源。
- 队伍、选中关卡、解锁进度、累计胜场和进行中的战斗状态随本地存档保存。

## 自动化结果

- `test_battle_system.gd`：队伍编成、岗位切换、属性、自动战斗、关卡解锁、奖励与存档通过。
- V0.1、V0.2 原有 11 组测试全部通过。
- 主场景无界面脚本解析错误，可在 Godot 4.7.2 无头模式正常启动。
- Windows x86_64 导出版已生成并通过启动冒烟检查。

## 手工验收建议

1. 在普通弟子名册选中弟子，点击“选中弟子入队”，确认原岗位改为“外山战斗”。
2. 编成一至三人后选择“山门试炼”，点击“开始自动战斗”。
3. 观察我方与敌方生命、回合战报，以及胜利后的两秒重复挑战。
4. 确认顶部宗门资源按关卡奖励增加，第一关胜利后第二关解锁。
5. 战斗中保存并读取，确认队伍、血量、关卡和自动战斗状态恢复。
