# 《青云宗》V0.8 UI设计规范

状态：负责人确认继续使用当前UI模式。

## 固定结构

- 顶部：宗门名称、等级、木材、灵石、灵谷、弟子数量、保存/读取状态。
- 左侧主体：12×8宗门地图。
- 右侧：固定420逻辑像素滚动管理栏。
- V0.8不改为全屏地图加弹出管理面板，不同时开发第二套导航架构。

## 视觉语言

- 主框使用深青玉石感底色，内容区使用米白/浅暖灰宣纸感，描边仅少量暗金。
- 正常操作为松绿/玉青，奖励与成长为暖金，危险为朱砂，错误同时配文字。
- 标题、区块标题、正文、辅助说明四级；正文和按钮在1280×720下保持清晰。
- 按钮包含默认、悬停、按下、焦点、禁用状态；进度条必须同时显示文字或数值。

## 交互

- 一个区块只突出一个主要操作，拆除等危险操作与普通操作分离。
- 资源始终使用完整名称“木材、灵石、灵谷”，禁止缩写为无法区分的“灵”。
- 长列表继续使用右侧滚动容器；快捷导航只调整滚动位置，不改变数据状态。
- 保存、施工、打造、装备和突破反馈必须明确成功或失败原因，不依赖日志。
- UI只调用GameState与SaveManager公开入口，不直接结算资源、战斗或存档。

## 可访问性与验证

- 状态使用图标/文字/形状共同表达，不只依赖颜色。
- 验证1280×720与1920×1080、长姓名、长数值、滚动位置和键盘焦点。
- Theme或素材缺失时界面仍须可运行并显示可读回退。
