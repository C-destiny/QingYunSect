# 《青云宗》V0.8 UI设计规范

状态：负责人于2026-10-17确认取消常驻右侧菜单，采用全幅地图与按需管理面板。

## 主界面结构

- 顶部：作为地图内部悬浮信息条显示宗门名称、等级、木材、灵石、灵谷、弟子数量和保存/读取状态；木材、灵石、灵谷、弟子使用独立图标与完整数值，不遮断地图主体。
- 主体：12×8宗门地图铺满顶部栏以下的可用区域，常态下不被管理菜单横向挤压。
- 底部：作为地图内部悬浮导航显示宗门、建设、弟子、养成、挂机五个图标入口；只负责打开并定位管理内容，不改变数据状态。
- 管理内容：从右侧覆盖显示的560逻辑像素滚动面板，点击建筑、资源点、锁定区域或底部入口时打开。
- 面板可由右上角“关闭面板”按钮、再次点击当前底部入口或Esc关闭，关闭后立即恢复完整地图视野；关闭操作必须消费本次输入，不能穿透到地图。
- 不维护另一套业务界面；覆盖面板继续复用原有GameState、SaveManager和管理控件。

## 视觉语言

- 主框使用深青玉石感底色，内容区使用米白/浅暖灰宣纸感，描边仅少量暗金。
- 正常操作为松绿/玉青，奖励与成长为暖金，危险为朱砂，错误同时配文字。
- 标题、区块标题、正文、辅助说明四级；正文和按钮在1280×720下保持清晰。
- 按钮包含默认、悬停、按下、焦点、禁用状态；进度条必须同时显示文字或数值。

## 交互

- 一个区块只突出一个主要操作，拆除等危险操作与普通操作分离。
- 资源始终使用完整名称“木材、灵石、灵谷”，禁止缩写为无法区分的“灵”。
- 长列表继续使用覆盖式滚动容器；快捷导航只负责打开面板并调整滚动位置，不改变数据状态。
- 保存、施工、打造、装备和突破反馈必须明确成功或失败原因，不依赖日志。
- UI只调用GameState与SaveManager公开入口，不直接结算资源、战斗或存档。

## 可访问性与验证

- 状态使用图标/文字/形状共同表达，不只依赖颜色。
- 顶部资源与底部导航图标统一来自`assets/ui/qingyun_ui_icon_atlas.png`，图标缺失时保留可读文字回退。
- 验证1280×720与1920×1080、全图/开面板状态、长姓名、长数值、滚动位置和键盘焦点。
- Theme或素材缺失时界面仍须可运行并显示可读回退。
