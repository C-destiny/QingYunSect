# V0.4 战斗界面信息规范

任务：QYS-V04-006。状态：已编码与测试，待负责人验收。

战斗面板只读取 `GameState` 与 `BattleCatalog`，不直接修改资源、血量、胜负或奖励。

## 展示内容

- 队伍：人数、姓名，以及每名成员的炼气层数、生命、攻击、防御和“参战中”状态。
- 队伍合计：生命、攻击、防御、累计胜场，并明确“生命为队伍共用，不采用逐人受击”。
- 关卡：分别展示选中关卡、正在挑战/等待重战状态、已解锁范围和最高通关进度。
- 敌方：名称、生命、攻击、防御以及当前关卡三资源奖励。
- 血量：我方共用生命和敌方生命均显示当前值/最大值，同时保留进度条。

## 同步规则

- `battle_changed` 刷新战斗状态；`disciples_changed` 额外刷新成员境界与实时属性。
- 入队、离队、战斗推进、突破、关卡选择和成功读档后均从状态重新生成显示，不缓存第二份战斗数据。
- 关卡下拉列表继续区分锁定项；战斗中禁止切换关卡。

## 布局边界

逻辑视口保持1920×1080，默认窗口1280×720并使用canvas_items缩放。侧栏最小宽度420，战斗文字自动换行，整个侧栏保留垂直滚动，因此新增信息不会截断后续关键按钮。专项测试分别以1280×720及1920×1080启动并核对关键控件与状态文本；本任务未替代最终版本的人工可视化试玩。
