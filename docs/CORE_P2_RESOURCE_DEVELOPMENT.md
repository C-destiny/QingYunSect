## 具体规则

- 粮食为负净收入时，用库存/当前净消耗估计耗尽时间；显示估计前提，不把突发支出和未来施工计入预测。无净消耗时显示持平/盈余，不显示无穷大。零库存显示缺粮；已有粮田岗位但恢复缓慢时说明继续生产，不错误要求建设新的灵田才能恢复。
- 发展建议按当前状态生成：优先补粮与基础岗位，再扩容招募、修炼突破、炼器打造及装备检查。普通弟子现有修炼仍保留；这是为未来核心弟子系统验证培养底座，不把普通弟子标为新副本出战角色。
- 旧“10次挂机胜利”等一次性目标仍是旧挂机目标。新准备建议无独立奖励、不新增领取标记，未实现的核心弟子与主动副本明确显示后续阶段。
- 资源缺口只在能等待积累时估算等待时间；零产出/负净收入提示先调整岗位，不显示错误的倒计时。预计时间不保证实际完成时间。
