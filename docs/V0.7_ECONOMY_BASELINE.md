# V0.7 经营与挂机基线

本文件记录QYS-V07-001核验到的V0.6已验收数值。它是后续平衡对照，不代表本任务已经修改数值。

## 经营基线

| 项目 | 当前值 |
|---|---:|
| 青松林基础产量 | 木材12/分钟/一层弟子 |
| 浅层灵石矿基础产量 | 灵石8/分钟/一层弟子 |
| 荒芜灵田基础产量 | 灵谷10/分钟/一层弟子 |
| 弟子灵谷消耗 | 每人1/分钟 |
| 缺粮采集倍率 | 50% |
| 生产建筑每总等级加成 | 对应资源+25% |
| 宗门每提升一级的生产加成 | +5% |
| 弟子每提升一层的个人采集加成 | +5% |

当前五类建筑均为1～3级。建造基础成本分别为弟子居木材40/灵石10、伐木场30/15、采灵坊50/25、灵田35/20、演武场60/40；升级到目标等级的成本为基础成本乘目标等级。

宗门等级为1～5级，繁荣要求依次为100、250、500、900。繁荣来自修为、已完工建筑等级和弟子境界；升级本身当前不扣资源。

## 挂机战斗基线

初始三名炼气一层弟子按稳定迁移职业为剑修、法修、剑修。无装备时队伍攻击约34.5；第一关防御2、生命120，因此约4回合获胜，加2秒重战等待后理论约10胜/分钟。

第一关每胜奖励木材20、灵谷10；上述初始满队理论约为木材200/分钟、灵谷100/分钟，另有三名弟子合计灵谷消耗3/分钟。每累计5胜掉落一件装备，理论约2件/分钟，直至60件库存上限。

这表明自动战斗的资源流入显著高于单个生产岗位。V0.4曾明确验收保留现行关卡奖励，因此V07-001不直接削减奖励；V07-006必须用长时样本比较以下方案后再由负责人确认：

1. 保持奖励，依靠领地解锁与确定性打造形成足够资源消耗。
2. 引入可解释的出战补给消耗，同时保持关卡奖励展示值。
3. 调整重战节奏或高关收益曲线，但不破坏已经获得的资源与关卡进度。

## V0.7结构决策

- 地图首版从8×6扩到12×8，但原区域、建筑和资源点坐标不变。
- 只使用木材、灵石、灵谷，不新增顶栏资源。
- 宗门等级仍为1～5，建筑等级仍为1～3。
- 新增炼器坊和藏经阁；装备打造成为主要资源消耗，藏经阁联动在线/离线修炼。
- 在平衡专项获得负责人确认前，不修改现有采集、粮耗、五关奖励和每5胜掉落值。

## 基线风险

- 战斗资源产出目前可能替代采集岗位；需要用实际成长时长而非单场奖励感受判断。
- 当前资源没有容量上限，长时挂机可以无限累积；V0.7优先增加有意义的消耗，不突然截断旧存档资源。
- 装备库存满后掉落跳过，打造必须在库存满时原子失败，不能扣除资源。
- 地图扩张会触及建筑坐标校验；version 1、2旧档必须先按原8×6范围验证，再补齐默认领地。
