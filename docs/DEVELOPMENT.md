# 开发约定

## 工作方式

1. 每次只实现一个可验证的小功能。
2. 修改后先运行项目，再提交代码。
3. 数据逻辑与视觉表现分离。
4. 宗门、角色、装备、挂机和肉鸽共享统一数据来源。
5. 以根目录 AGENTS.md、PROJECT_DEVELOPMENT_PLAN.md 和当前已批准 Issue 为执行依据；不提前实现当前版本范围之外的功能。编码测试通过进入待验收，负责人明确确认后才计入完成。

## 目录规划

- `assets/`：图片、字体、音频等源资源
- `data/`：资源配置与数据定义
- `scenes/`：Godot 场景
- `scripts/`：GDScript 代码
- `tests/`：自动化和回归测试
- `docs/`：设计与开发文档
- `builds/`：本地导出文件，不提交 Git

## 提交原则

- `main` 始终保持可运行。
- 提交信息用简洁中文描述结果。
- 不提交 `.godot/`、构建产物、日志或本机配置。
