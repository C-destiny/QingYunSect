# 核心人物视觉与未来玩法设想

## V0.8实施边界

V0.8只建立崔云川、周墨的角色视觉模型并在现有UI中提供视觉展示。两人不进入弟子列表、战斗队伍、职业规则或version 3存档，不改变现有普通弟子与剑修/法修系统。

## 崔云川

- 称号：剑心守道。
- 性格：沉稳、执着、责任感强、理性、外冷内热。
- 视觉：深青蓝、白、银，少量金色；轻甲、护腕、剑修腰封、长剑。
- 视觉关键词：稳、锋利、克制、可靠。

未来玩法设想（不在V0.8实现）：近战主力、稳定前排、快速剑技、位移、单体爆发、格挡与防御反击。

## 周墨

- 称号：机巧道人。
- 性格：乐观、聪明、细心、务实，带一点幽默。
- 视觉：保留黑框眼镜；靛蓝、青蓝、米白，铜与青玉点缀；工具袋、卷轴、机关匣。
- 视觉关键词：聪明、灵活、生活化、可靠。

未来玩法设想（不在V0.8实现）：法术、机关、阵法、控制、增益、范围辅助与资源辅助。

## 关系

两人是亦敌亦友的长期搭档，做事方式不同但高度信任。关系基调为“一个守住底线，一个总能找到另一条路”。该关系属于未来叙事设想，V0.8不增加剧情系统。
