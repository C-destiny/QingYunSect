## 本批玩法与实施边界

建成现有藏经阁后，空闲/修炼弟子可花20灵石永久学习一门试制功法；每人各学一次，重复学习不扣款。简剑诀攻击+3，守元诀生命+30；均为本项目临时内容名与采用值，不冒称《山门与幻境》已核验数据。每人可学两门，同时只运转一门，也可停用；学习不会自动运转，切换免费。无新货币/设施/功法等级/多槽/图鉴。

学习、切换、停用均通过GameState规则；UI保存失败后恢复完整快照与消耗、已学集合、运转项，错误提示不被刷新覆盖。出战/挂机/采集不可操作。功法加成经get_disciple_battle_stats统一叠加，普通挂机与主动副本同源，入场快照沿原规则；局内强化不写进永久功法，重开不会重复累加永久属性。不同弟子独立学习与选用。

scripts/data/technique_catalog.gd集中费用、名称、效果与校验。GameState根techniques以稳定弟子ID的十进制字符串为键，值为learned合法无重复ID数组和active空值或已学ID；拒绝缺失弟子、未知功法、重复ID及未学运转，失败完整回滚。
