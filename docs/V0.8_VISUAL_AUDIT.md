## 信息优先级

1. 顶栏首先回答当前资源、净产量和关键告警。
2. 地图首先回答可操作区域、建筑状态和当前选择。
3. 侧栏每次突出一个主操作；危险操作使用朱砂但不常驻抢占注意力。
4. 弟子、装备和战斗优先展示会改变决策的属性，解释性明细折叠或降级。
5. 保存、施工完成、领奖等短反馈不遮挡地图连续操作。

## 概念基线结论

- 正式方向采用风格化半写实国风、正常人体比例、弱线稿与清晰材质；地图优先保证小尺寸轮廓。
- 保留顶部资源栏、左侧地图、固定右侧滚动栏。概念图的70%地图、30%侧栏只作为构图与色彩参考，其偏卡通细节不再作为人物或建筑定稿标准。
- 概念图中的复杂建筑细节不直接视为运行素材；实际资产须按等距尺寸、透明边界和性能预算重新制作。
- 位图中不承载可读中文；所有正式文字继续由 Godot 控件渲染。
