# V0.8 宗门挂机美术、UI与体验定稿计划

状态：已批准开发  
批准依据：负责人于2026-10-17明确回复“验收完毕，开始开发V0.8”。  
版本目标：在不改变V0.7玩法、数值和存档语义的前提下，把宗门挂机阶段打磨为视觉统一、信息清晰、可持续扩展的阶段成品，并形成V0.9肉鸽可复用的视觉规范。

## 首版边界

1. 视觉方向为风格化半写实国风：正常人体比例、弱线稿、清晰材质，以青蓝/青灰、米白、暖木和少量金色为主；地图资产优先保证小尺寸轮廓，不追求照片级写实，避免阴暗写实和仙侠网游高光堆叠。
2. 保留12×8逻辑地图、104×52等距地块、七类建筑和所有坐标；美术替换不得改变网格判定。
3. V0.8不新增玩法、资源、境界、职业、装备模板、建筑、关卡或奖励数值，不修改version 3存档字段。
4. 保留顶部资源栏，将地图扩展为主体全幅视野；取消固定右侧菜单，改用底部五入口与按需覆盖式滚动管理面板。所有按钮仍调用现有GameState/SaveManager入口，不把结算逻辑搬到界面。
5. 先建立代码化Theme、组件和布局，再接入位图资产，保证素材尚未完成时仍可运行和回退。
6. AI生成位图均记录生成方式、最终提示词和用途；项目自制代码图形记录为原创。外部字体、音效或素材必须附许可，不使用来源不明资源。
7. 目标分辨率为1280×720默认窗口和1920×1080逻辑视口；文字、颜色和交互状态必须保持可读。
8. V0.9肉鸽、多人联机、40×40地图、多山头和正式全量音频继续暂缓。

## 开发流程

### QYS-V08-001：视觉审计、风格规范与概念基线

- 审计现有颜色、字体层级、布局密度、地图比例和信息优先级。
- 固化调色板、描边、圆角、间距、字号、图标和等距素材规范。
- 生成一张宗门主界面概念基线，明确哪些属于方向参考、哪些可直接入库。

验收：规范能覆盖地图、顶栏、侧栏、弹窗和状态反馈；概念图保持当前玩法结构；素材来源可追溯。

### QYS-V08-002：全局Theme与基础UI组件

- 建立统一按钮、面板、标签、进度条、选择器、滚动区和弹窗样式。
- 明确默认、悬停、按下、禁用、成功、警告和危险状态。
- 将主场景从散落覆盖值迁移到可复用Theme，保留必要局部语义色。

验收：基础控件风格一致；文字对比度和状态辨识明确；不改变交互与数据逻辑。

### QYS-V08-003：等距地形与宗门环境美术

- 制作104×52等距地块、已解锁/锁定区域、道路、山石、植被和云雾层。
- 保持12×8点击换算和占用边界，增加层次但不遮挡交互。

验收：原坐标与预览判定不变；三种区域清晰；1280×720下地图主体可辨认。

### QYS-V08-004：七建筑与资源点视觉资产

- 为弟子居、伐木场、采灵坊、灵田、演武场、炼器坊、藏经阁建立一致等距素材。
- 补齐三资源点、大殿、施工、升级、选中和不可放置反馈。

验收：建筑轮廓可区分且方向、比例、光源统一；施工和选择状态清楚；素材许可完整。

### QYS-V08-005：弟子、职业、装备与打造界面定稿

- 优化弟子名册、详情、岗位、境界、修为和装备层级。
- 为两职业、三部位、三品质和打造配方建立图标/颜色规范。
- 保持键鼠操作清楚，减少长文本堆叠。
- 建立崔云川、周墨两名核心人物的风格化半写实视觉模型并接入视觉展示；本版不新增角色玩法、技能、职业、队伍或存档字段。

验收：玩家可快速识别弟子状态与装备差异；打造条件和失败原因无需阅读日志即可理解。

### QYS-V08-006：挂机战斗、离线收益与操作反馈

- 定稿战斗队伍、敌我状态、日志、奖励和自动战斗反馈。
- 优化离线收益、目标领奖、保存、解锁、施工完成等弹窗和短反馈。
- 加入轻量动效，但胜负和计时不得依赖动画。

验收：开始、等待、胜利、失败、离线结算和保存失败状态可区分；动效关闭或丢帧不影响逻辑。

### QYS-V08-007：可读性、分辨率、性能与全量回归

- 验证1280×720、1920×1080、全图/开面板状态、面板滚动、长文本、色弱可辨和焦点状态。
- 覆盖47组既有逻辑回归、主场景运行、资源加载、内存和长时挂机。

验收：V0.7功能与存档无回归；无明显遮挡、溢出或模糊；新增资产不过度增加启动时间和内存。

### QYS-V08-008：Windows候选包与阶段验收

- 更新0.8版本标识，导出Windows x86_64候选包。
- 独立启动，记录大小、SHA-256、素材清单、已测/未测及人工验收项。

验收：候选包可运行；全部任务进入TESTED；负责人明确确认前保持open，不宣布V0.8完成。

## 版本完成标准

- 宗门地图、七建筑、三资源点、弟子装备、挂机战斗和离线收益拥有一致视觉语言。
- 玩家在默认窗口下能清楚理解当前资源、目标、选择状态和下一步操作。
- V0.7存档、玩法、数值、结算和岗位互斥完全保留。
- 所有项目素材来源、生成方式和许可可追溯。
- 自动回归、视觉检查、性能检查、Windows候选包和负责人试玩验收通过。
