# studio-asset-spec — Codex project adaptation

Derived from Donchitos/Claude-Code-Game-Studios (asset-spec), MIT, pinned commit 05ad7c8a5b8aa2aa86bbd3439ae7cf7295cac418.

For each new asset, record purpose/layer, references and roles, aspect, actual dimensions, format, alpha, filtering, game footprint, projection, palette, materials, light, density, frame/anchor, entrance, collision/hit role, source/tool/prompt/path/hash and remaining mismatches in the existing sample/source report. Inspect existing assets first. Use system imagegen. Pure scenery never changes legal building cells. A prompt is not an asset and an image is not a runnable sample. Do not invent budgets, create duplicate registries, run upstream hooks/config, install related dependencies, dispatch agents or rewrite gameplay. User approval applies to the authorized scope, not repeated per-file requests. Original reference: references/upstream.md; pinned source/license in .agents/game-studios.lock.json.
